# Miracle Alpaca Tarot (奇蹟羊駝塔羅)

An open-source interactive web application that combines traditional tarot divination with artificial intelligence, featuring a charming alpaca theme.

一個結合傳統塔羅占卜與人工智慧的互動式網頁應用程式，並以可愛的羊駝為主題。

## Features (功能特點)
- **AI-Powered Readings**: Utilizes advanced AI models to provide dynamic and personalized tarot card interpretations.
- **Interactive Interface**: A user-friendly web interface for selecting and displaying tarot cards.
- **Alpaca Theme**: Unique and engaging visual elements centered around alpacas to enhance user experience.

## Tech Stack (技術棧)
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend/Integration**: Node.js / Python
- **AI Integration**: Google AI Studio / Gemini API / OpenAI API
